# Guadalajara (city): municipal law in git

Part of [lexifina/global-law](https://github.com/lexifina/global-law), one git history for every country's law: this is the law of Guadalajara, Jalisco, Mexico, which global-law reads at `mexico/jalisco/guadalajara/acts/`.

The municipal law of Municipio de Guadalajara (Jalisco, Mexico) as a git history: its reglamentos, one file per article, one paragraph per line, so `git log`, `git blame` and `git diff` work article by article.

It follows the shared design of [lexifina/global-law](https://github.com/lexifina/global-law), which places it at `mx-jal-guadalajara/`. The law of the State of Jalisco is in [lexifina/mexico-jalisco-law](https://github.com/lexifina/mexico-jalisco-law), and Mexico's federal law in [lexifina/mexico-law](https://github.com/lexifina/mexico-law).

The text is in Spanish, exactly as the source prints it.

## What this repository holds

101 reglamentos so far, each as its **current consolidated text only** (the oldest version available from the source), added in parts. Guadalajara has no separate Bando de Policía y Buen Gobierno: the city's own portal says its functions are fulfilled by the Reglamento de Justicia Cívica del Municipio de Guadalajara, which comes first, with the Código de Gobierno, the Reglamento Orgánico and the Reglamento de la Administración Pública Municipal.

## Source

Portal de Transparencia del Gobierno de Guadalajara (transparencia.guadalajara.gob.mx), "Los reglamentos federales, estatales y municipales" (art. 8, fr. II, inc. d), list of reglamentos municipales vigentes, <https://transparencia.guadalajara.gob.mx/articulo-8/ii-la-informacion-sobre-el-marco-juridico-aplicable-al-y-por-el-sujeto-obligado-que-comprende/d-los-reglamentos-federales-estatales-y-municipales>. For each reglamento municipal vigente the portal gives its name, the date of its last reform ("Última reforma") and its current consolidated text as a PDF with a text layer. Earlier versions are not published there.

## Dates

- Each reglamento is one commit, dated at **noon, America/Mexico_City, on the date of its last reform** as the source records it. Its original text and earlier versions are not shown, because the source does not publish them.
- Versions dated after the retrieval day would go on the `futuro` branch, never merged into `main`.

## Files

`<reglamento>/art-005.md` is Artículo 5, `art-005-bis.md` Artículo 5 bis; `encabezado.md` holds the title and anything printed before Artículo 1. Chapter headings, transitorios and the reform notes the source prints stay in the file of the article they follow. One paragraph per line.

## How it is checked

- Every version is read back from git on its day (`tools/check_repo.py`) and must match `corpus.json`.
- The letters and digits of every version equal those of the source PDF read again with an independent reader (poppler's pdftotext), so no word is lost or added.
- Health checks: no merge commits, commit dates never go backwards, nothing dated in the future, and every commit's trailers parse.

## Limits

This is not an official publication. The binding text is the one published in the Gaceta Municipal de Guadalajara. Only the reglamentos listed above are included, each as its current text only.
